# G Learning Games — GitHub Pages package

This folder is a self-contained static site prepared for GitHub Pages.

## Pages

- `index.html` — landing page with the two new games and the previous demos tile.
- `previous-demos.html` — earlier phonics demos and G-Learning island examples.
- `games/` — the two current playable games and their local data/assets.
- `previous/` — earlier demos linked from the archive page.

## GitHub Pages

Copy the contents of this folder into the root of the intended GitHub Pages repository, or into its `docs` folder. In the repository’s Pages settings, publish from the matching branch and folder. Keep the relative folder structure intact; the games and assets use relative paths. `.nojekyll` is included.

The earlier Bubble Pop demo uses camera hand tracking in camera mode and can ask visitors to grant camera permission. Its mouse mode is available without camera access.

The project brief is a separate submission document and is not included in this website package.
